# The Breach — Interactive Cybersecurity Portfolio

**The Breach** is an interactive cybersecurity storytelling experience designed as a simulated Security Operations Center (SOC) desktop environment.

Instead of presenting a traditional portfolio, visitors investigate a fictional cyberattack that has erased a digital identity. By exploring case files, analyzing evidence, interacting with a terminal, and solving cybersecurity challenges, visitors gradually recover information and reconstruct the identity.

🌐 **Live Demo:** https://rishima115.github.io/The-Breach/

## Key Features

- **Interactive Boot Sequence:** Simulates a system startup and investigator authentication process.
- **SOC Desktop Environment:** Provides an operating-system-style interface with multiple interactive applications.
- **Incident Case Files:** Presents a fictional security incident, investigation status, and recovery objectives.
- **Evidence Locker:** Provides an interface for exploring investigation evidence.
- **Interactive Terminal:** Supports command-based interaction within the simulated environment.
- **Network Investigation:** Includes a simulated network environment with connected devices and investigation challenges.
- **Password Vault:** Introduces password-based evidence unlocking.
- **Phishing Investigation:** Challenges visitors to identify suspicious email activity.
- **Memory Recovery:** Unlocks portfolio information through interactive challenges.
- **Dynamic Progress Tracking:** Displays investigation and identity recovery progress.

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rishima115/The-Breach.git
   ```

2. Navigate to the project directory:

   ```bash
   cd The-Breach
   ```

3. Open `index.html` in a web browser.

No additional dependencies or backend configuration are required for the current implementation.

## Project Objective

The goal of The Breach is to combine cybersecurity concepts with interactive storytelling and portfolio presentation, creating an engaging experience where visitors investigate rather than simply read about the developer.
